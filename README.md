# TAREA FASE 1.4

## Implementación de una API pequeña con CRUD básico cuya función es almacenar y mostrar tareas con
ID, título, y estado completado: TRUE o FALSE

### Como ejecutar el proyecto
1. Instalar dependencias:
npm install

2. Arrancar servidor:
node index.js

3. Datos almacenados en array (daos.js)
Prueba de datos en url: /task
